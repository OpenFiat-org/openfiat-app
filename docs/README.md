# openfiat-app documentation

Extended documentation for `openfiat-app` lives here. High-level architecture and diagrams belong in this directory; user-facing docs are published to [docs.openfiat.network](https://github.com/OpenFiat-org/openfiat-docs).

## Contents

- [`getting-started.md`](getting-started.md) — running the app locally, and
  what it takes to see live data instead of the demo data every route ships
